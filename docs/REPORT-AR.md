# Qubedu — التقرير التفصيلي

منصة تعليمية كاملة: موقع ويب + تطبيق موبايل (أندرويد/آيفون) بنفس المميزات، 4 لغات (عربي، إنجليزي، فرنسي، إسباني)، 6 تصميمات × 8 ألوان × فاتح/داكن.

## 1) ملخص سريع
| | الويب | التطبيق |
| --- | --- | --- |
| عدد الشاشات | 57 صفحة | 52 شاشة |
| المميزات | كل المميزات | نفس المميزات (القائمة بالأسفل) |
| اللغات والتصميمات | 4 لغات، 6 تصميمات، 8 ألوان | نفس الشيء |
| الصوت للمعلم | ✅ | ✅ |
| الاختبارات الآلية | أكتر من 150 اختبار — كلها ناجحة | بناء أندرويد وآيفون ناجح |

## 2) المكوّنات (الأجزاء اللي بتشتغل على السيرفر)
- **الموقع (Web)**: React + Vite. يشتغل كتطبيق (PWA) يتثبت على الشاشة الرئيسية ويشتغل أوفلاين جزئياً.
- **التطبيق (Mobile)**: Expo / React Native — أندرويد وآيفون من نفس الكود.
- **السيرفر الرئيسي (API)**: Node.js (Hono) + قاعدة بيانات PostgreSQL + Redis. 25 مجموعة من الواجهات.
- **سيرفر الوقت الحقيقي**: Go — الشات، الكتابة الآن، الإشعارات الفورية، إشارات البث المباشر.
- **خدمة الذكاء الاصطناعي**: Python — حل المسائل خطوة بخطوة، البحث داخل محتوى الكورسات، تصحيح المقالات.
- **الحماية**: كلمات سر مشفّرة (argon2)، جلسات آمنة، حماية من التكرار والهجمات (rate limit)، روابط ملفات موقّعة، صلاحيات لكل دور (طالب / معلم / مدير).

## 3) كل المميزات
**الحساب**: تسجيل، دخول، نسيت كلمة السر، تأكيد الإيميل، الجلسات النشطة، تصدير/حذف البيانات، الخصوصية.

**الرئيسية**: لوحة اليوم، التحدي اليومي، السلسلة (Streak)، النقاط والمستويات، صندوق "ذاكر الآن" (دروس لم تكتمل، اختبارات بعد الدرس لم تؤخذ، أخطاء تتراجع).

**قاعة المذاكرة**: نقاشات، أسئلة حسب المادة، ترتيب الإجابات، "مفيد"، أفضل إجابة (+نقاط)، إجابة موثّقة من المعلم، ملاحظات مذاكرة، استطلاعات، حفظ ومجموعات محفوظات، نصائح مذاكرة (24 ساعة) بتفاعلات تعليمية.

**الدروس المصوّرة**: دروس، دروس الدقيقة الواحدة، قنوات المعلمين، سلاسل الدروس، السجل، فهرس الدرس من التوقيتات، اختبار بعد الدرس، ملاحظات خاصة مرتبطة بلحظة في الفيديو، فلتر المادة، استوديو المعلم والإحصائيات.

**منطق التعلّم (مترابط)**: مشاهدة الدرس تتحسب وقت مذاكرة وتكمّل السلسلة (بحد أقصى منطقي يمنع الغش بالتقديم السريع)، نقاط عند إكمال نصف الدرس (مرة واحدة، وحد يومي)، نتيجة الاختبار بتوديك للدروس المرتبطة، الأخطاء تتحول لبطاقات مراجعة بدون تكرار.

**معمل النطق**: اسمع، اتكلم، تقييم كلمة بكلمة، الكلمات الضعيفة → تدريب أو بطاقات، نقاط. القراءة بصوت عالي بلغة النص نفسه في المنشورات والإجابات والاختبارات والبطاقات والمعلم الذكي.

**المجموعات**: مجموعات مذاكرة، قنوات، ملفات المجموعة، ترتيب الأعضاء، طلبات الانضمام.

**الرسائل**: شات فردي وجماعي، "يكتب الآن"، تمت القراءة، ملفات، رسائل صوتية.

**الاختبارات**: اختبارات وامتحانات، منشئ الاختبارات (اختيار، صح/خطأ، إكمال، ترتيب...)، تدريب ذكي، مراجعة النتيجة، إحصائيات لكل سؤال.

**مذاكرتي**: البطاقات بالتكرار المتباعد، الخطة الأسبوعية، جلسات المذاكرة، مؤقت التركيز، الإتقان لكل مادة، عدّاد الامتحانات، المهام والملاحظات.

**الذكاء الاصطناعي**: المعلم الذكي، حل المسائل الرياضية، تصحيح المقالات، مساعد المذاكرة.

**مساحة العمل**: مستندات، جداول بمعادلات، عروض تقديمية، سبورات، تصدير Office.

**النماذج**: منشئ نماذج، نماذج بدرجات، تحليلات، تصدير CSV.

**المكتبة**: كتب وملفات بنظام مراجعة وموافقة.

**الفصول**: كورسات، واجبات بملفات، تصحيح ودرجات، حضور، مواد الكورس، إعلانات.

**البث المباشر**: كاميرا، مايك، مشاركة الشاشة، سبورة، رفع اليد، إدارة الطلاب، تسجيل، شات.

**الورش وجلسات المراجعة**: مع تأكيد الحضور.

**الملف الشخصي**: متابعة، لوحة الشرف، الإنجازات، النتائج.

**الإشعارات**: داخل التطبيق وفورية.

**لوحة الإدارة**: 12 قسم + التحكم في كل ميزة (مفعّلة / مقفولة برسالة / مخفية / الصفحة متوقفة).

## 4) الجديد في الجولة دي
### الصوت للمعلم
- **تعليق صوتي على الواجب**: المعلم يسجّل ملاحظة صوتية مع الدرجة، والطالب يسمعها في صفحة الواجب.
- **إعلانات صوتية** في الكورس (ممكن صوت بس من غير نص).
- **تعليقات وإجابات صوتية** في قاعة المذاكرة والدروس.
- الملفات الصوتية محمية: لازم تكون مرفوعة من نفس الشخص، ونوعها صوت فعلاً، والروابط الخاصة موقّعة.
- شغّال على الويب (تسجيل من المتصفح) وعلى التطبيق (تسجيل من الموبايل).

### التطبيق بقى زي الموقع
اتضاف للتطبيق كل اللي كان ناقص: مذاكرتي كاملة، المعلم الذكي ومساعد المذاكرة، الفصول والواجبات والتصحيح، المكتبة، الورش، النصائح، النماذج (إنشاء وتعبئة وردود)، المنظّم، الاستوديو، معمل النطق، البحث والاستكشاف والوسوم، مكتبة الدروس والسلاسل والقنوات ودروس الدقيقة، الصفحات التعريفية، مجموعات المحفوظات، منشئ الاختبارات وإحصائياته، استعادة كلمة السر، الإعدادات كاملة، إنشاء البث المباشر.

### تحديث المميزات القديمة
- المجموعات: ملفات، ترتيب الأعضاء، قنوات، طلبات انضمام، إنشاء مجموعة.
- الملف الشخصي: النتائج، المجموعات، القناة.
- الرئيسية: اختصارات سريعة وبطاقة اليوم.
- تفاعلات النصائح بقت تعليمية وموحّدة بين الموقع والتطبيق والسيرفر (👍 💡 🙏 🤯 👏 🔥).
- البطاقات: منع التكرار في نفس المجموعة.
- الجمع في اللغات صحيح (مثلاً: سؤال واحد / سؤالين / 3 أسئلة / 11 سؤالاً).

## 5) الفرق بين النسختين
المميزات واحدة. الفروق الوحيدة طريقة التشغيل:
| الميزة | الويب | التطبيق |
| --- | --- | --- |
| المستندات والجداول والعروض والسبورة | محرر كامل | نفس المحرر بيفتح جوه التطبيق وانت مسجّل دخول تلقائياً |
| غرفة البث المباشر | في المتصفح | إنشاء البث من التطبيق، والغرفة بتشتغل جوه التطبيق بالكاميرا والمايك |
| لوحة الإدارة | كاملة | نفس اللوحة جوه التطبيق |
| تحليلات النماذج المتقدمة | كاملة | الأساسي في التطبيق، والمتقدم نفس شاشة الويب جوه التطبيق |
| التعرّف على الكلام (معمل النطق) | Chrome / Edge / Safari | في نسخة التطبيق المبنية (APK). في Expo Go الاستماع بس |
| التثبيت | PWA من المتصفح | APK / متجر |

الشاشات اللي بتفتح "جوه التطبيق" مش بتطلّعك برا: الدخول بيتنقل تلقائياً بكود آمن صالح 60 ثانية لمرة واحدة، والقوائم بتختفي فتبان كأنها جزء من التطبيق، وأي رابط فيها بيرجعك للشاشة الأصلية في التطبيق.

## 7) ملف APK
بيئة العمل دي سياسة الشبكة فيها منعت الوصول لـ `dl.google.com` (أدوات أندرويد SDK اللازمة لبناء APK)، فماقدرتش أبني الملف هنا. حلّين:
1. **من عندك بأمر واحد** (موصى به): على أي كمبيوتر فيه Node.js:
   ```bash
   cd source && corepack enable && pnpm install && cd apps/mobile
   EXPO_PUBLIC_API_URL=https://دومينك.com EXPO_PUBLIC_WEB_URL=https://دومينك.com npx eas build --platform android --profile preview
   ```
   محتاج حساب مجاني على expo.dev، وبيرجعلك رابط تحميل APK.
2. **أبنيه أنا هنا**: من إعدادات البيئة (قائمة البيئة في شريط عنوان الجلسة ← Edit ← Network access) اختار مستوى وصول أوسع أو ضيف `dl.google.com` في Allowed domains مع تفعيل "Allow package managers"، وبعدها قولي "ابني الـ APK".
